Our application

Make a Friend operates an AI assistant web application for business teams. It connects to the user's own Google account through Google's permission screen, and it uses only the Google data the user explicitly allows, to help that user get their work done. Its purpose is to turn information already sitting in the user's own Google account into answers and drafts on demand, instead of making the user search and copy by hand.

With the user's permission, the application can:

  • connect the user's Google Account (name, email address, profile picture) so the app can work on that user's behalf;
  • read and summarize the Gmail messages and Drive files the user chooses, so the user can ask a question in plain language and get an answer drawn from their own content;
  • search that linked Google content to retrieve the right email, thread, or document for a task;
  • draft replies, notes, and documents with AI assistance and, when the user asks, save the result back to the user's Google account.

We request only the Google scopes a feature needs, we use the data solely to deliver that feature for the user who granted it, and we do not sell it or use Gmail and Drive content for advertising. Access can be withdrawn at any time from the user's Google Account permissions page. The Privacy Policy lists exactly what we collect, how we use and share it, how long we keep it, and how to have it deleted; the Terms of Service cover use of the app and the consulting services.
